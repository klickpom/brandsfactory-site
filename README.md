## ⚡ خطوات رفع الموقع على Hostinger في أقل من دقيقتين

كما يظهر في لوحة تحكم استضافتك على Hostinger:

1. **الدخول إلى لوحة التحكم (hPanel)**:
   - افتح لوحة التحكم الخاصة بالدومين: `brandsfactory.site`.

2. **فتح مدير الملفات (File Manager)**:
   - من قسم **أساسيات**، اضغط على زر **مدير الملفات (File Manager)** أو `فتح`.

3. **الدخول إلى مجلد `public_html`**:
   - بعد فتح مدير الملفات، ادخل إلى المجلد الرئيسي للموقع وهو `public_html`.
   - إذا وجدت أي ملف افتراضي قديم اسمه `default.php` أو `index.php` تابع لصفحة الترحيب بهوستنجر، يمكنك حذفه.

4. **رفع الملفات**:
   - قم برفع ملف `index.html` والمجلد `assets` بما يحتويه (أو قم بضغط كل الملفات في ملف `site.zip` وارفعه ثم اضغط `Extract` / فك الضغط داخل `public_html`).

5. **المعاينة**:
   - افتح متصفحك وادخل على: [https://brandsfactory.site](https://brandsfactory.site) وستجد الموقع يعمل مباشرة وبشكل فوري مع شهادة SSL الأمان المجانية المفعلة!

# نموذج تجريبي — موقع عيادة أسنان (3 باقات في موقع واحد)

ديمو بيع، مش منتج حقيقي. موقع واحد بيشتغل بـ 3 باقات: **عيادة** (6,500 جنيه) · **عيادة+** (13,000 جنيه) · **مركز** (22,000 جنيه). الزائر يبدّل بينهم من الشريط المثبّت فوق، والمزايا الأعلى بتظهر مقفولة بقفل عنبري بدل ما تتخبّى.

## التشغيل

موقع ثابت 100% — مفيش سيرفر ولا قاعدة بيانات ولا مكتبات خارجية. ارفع المجلد ده على أي استضافة ثابتة (Hostinger `public_html`) واشتغل على طول.

## تعديل المحتوى

كل المحتوى في ملف واحد: **`data/clinic-data.js`**

| عايز تغيّر إيه | مكانه |
|---|---|
| اسم العيادة / العنوان / المواعيد / التليفون | `clinic` |
| رقم واتساب الوكالة (اللي بيستلم العملاء) | `OWNER_WHATSAPP` — **غيّره قبل أي نشر حقيقي** |
| الخدمات والأسعار | `services` |
| مواعيد بكرة (الصفوف السبعة) | `appointments` |
| الدكاترة (باقة مركز) | `doctors` |
| قائمة المرضى (20 مريض) | `patients` |
| قوالب الرسايل الافتراضية | `templates` |
| أرقام التقارير | `reports` |

## تغيير رقم الوكالة

افتح `data/clinic-data.js` وعدّل السطر:

```js
OWNER_WHATSAPP: '20100000000', // TODO: replace
```

حط رقمك بالصيغة الدولية من غير `+` ولا مسافات (مثال: `201001234567`). الرقم ده بيستقبل رسايل «مهتم بباقة …» من شريط «عاجبك؟» اللي تحت.

## الحالة والتخزين

- كل حالة الزائر في `localStorage` بنطاق `bf_clinic_demo_*` (الباقة الحالية، التذكيرات المبعوتة، القوالب المعدّلة، تسجيل الدخول التجريبي، الصلاحية).
- الباقة بتظهر في الـ URL كهاش (`#basic` / `#plus` / `#center`) عشان تقدر تبعت لينك يفتح على باقة معينة.
- زر **إعادة تعيين البيانات** في الفوتر بيمسح كل حاجة ويرجع الديمو لحالته الأولى.

## سلوك واتساب

- زر **تذكير** الفردي بيفتح `wa.me` برسالة التذكير معبّأة بالعربي (على الموبايل يفتح التطبيق، على الديسكتوب يفتح WhatsApp Web).
- **تذكير الكل** بيعمل الأنيميشن المتتابع (400ms بين كل صف) ويحدّث العدّادات مباشرة — من غير ما يفتح 7 تابات (المتصفحات بتحظر ده).
- فورم الحجز في الصفحة العامة بيبعت رسالة «حجز جديد من الموقع» على رقم العيادة.

## الأداء

- الوزن الكلي ≈ 280 كيلوبايت شامل الخطوط والصور.
- الخط (IBM Plex Sans Arabic) مستضاف محلياً في `/fonts` — مفيش Google Fonts CDN.
- الصور WebP مع `width`/`height` صريحة وتحميل كسول تحت الطية.
